# Strategy feedback V2 contract

`strategy-feedback-v2` is a read-only routing artifact derived from one
identity-bound robustness verdict. It repeats the strategy, experiment,
candidate, data, policy, engine, runtime, code, and evaluation-context
identity so feedback cannot be detached from its evidence.

It carries `robustness_verdict_id`, the ordered reason codes, the fail-closed
action, terminal status, optional parent strategy lineage, and a canonical
`feedback_id` hash. Feedback never turns technical evidence into an economic
rejection and never creates Paper or Live permission.
